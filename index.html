ℹ️ About This Project

This project uses Artificial Intelligence and image classification to analyze uploaded or camera-captured skin images.

  • 📷 Capture a skin image using the camera.
  • 🖼️ Upload an existing skin image.
  • 🤖 AI analyzes the image.
  • 📊 Shows the predicted condition and confidence.
  • 🩹 Provides general symptoms and precautions.
  • ⭐ Shows an educational Skin Health Score.
  • 📜 Saves previous analysis results in History.
  • 👤 Stores patient profile information for the analysis report.

Important: This system is for educational and project demonstration purposes only. It does not provide a medical diagnosis. For medical concerns, consult a qualified dermatologist.
